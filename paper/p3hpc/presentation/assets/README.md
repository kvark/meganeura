# Slide images

`unreal-tournament.jpg` is an unmodified Unreal Tournament (1999) gameplay
screenshot from GOG's [store listing](https://www.gog.com/game/unreal_tournament_goty)
for the Game of the Year Edition (product 1207658692). It shows the released
game: a Domination match, with the rocket launcher in hand and an opponent
carrying a minigun. Game and artwork: Epic Games / Digital Extremes. It
illustrates the opening discussion of graphics hardware; it is not a Meganeura
integration or benchmark.

- [Original image](https://web.archive.org/web/20230511061542/https://images.gog-statics.com/e2effd1bd18b5ca2999052fe4e751faa11bec49fab4da5d44a7a971e3027e6f1.jpg),
  710×533, SHA-256 `69aeca9f2c72109b5d98bf473fa907659adb47866f3c7e443fa192912998a42b`.
- Retrieved October 21, 2026 from the Internet Archive's May 11, 2023 capture
  of GOG's image server, which returned errors that day.
- Copyright remains with the game rights holders; this is not a CC-licensed asset.
